## 内容原则

优先使用一手来源，核实发布日期与事件日期，区分事实、推断和未知。重要结论尽可能交叉验证，避免重复收录、旧闻重包装和无依据的趋势判断。没有足够重要的新信息时减少条目，不为凑数降低质量。
