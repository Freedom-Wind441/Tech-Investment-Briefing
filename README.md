# 科技与投资深度简报

每日整理值得关注的科技与投资信息，保留证据、不同观点和可继续验证的问题，便于阅读、检索与长期回顾。

## 关注领域

- 人工智能：模型、Agent、应用与技术进展
- 金融投资：宏观经济、全球市场、公司基本面与资产定价
- 科技硬件：GPU、CPU、半导体与消费电子
- 计算机技术：软件开发、Android、开发工具与开源项目
- 学术研究：计算机、数学与经济学前沿成果

## 阅读方式

每期提供两种归档格式：

- **Markdown**：直接在 GitHub 阅读，便于检索和查看修订。
- **PDF**：下载后阅读、打印或离线保存。

ChatGPT 同步输出当期完整简报。

## 内容原则

优先使用一手来源，核实发布日期与事件日期，区分事实、推断和未知。重要结论尽可能交叉验证，避免重复收录、旧闻重包装和无依据的趋势判断。

简报以过去 24 小时的重要进展为主，必要时补充背景。没有足够重要的新信息时减少条目，不为凑数降低质量。

## 归档与修订

报告按北京时间日期归档：

- Markdown：`reports/YYYY/YYYY-MM-DD.md`
- PDF：`pdf/YYYY/YYYY-MM-DD.pdf`

同一期发现错误或获得重要补充时，更新原文件并记录修订说明。Markdown 与 PDF 保持内容一致。
